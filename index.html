L&D reporting data lived entirely in CSOD flat-file exports — no database, no SQL. Raw files were structurally broken for Power BI: missing assignment attribution, unresolved due dates, and survey responses stored long-format (one row per question) instead of wide. Fixing it manually took a full day every reporting cycle.

Approach

Built two pandas ETL scripts that run monthly with a single variable change. The first joins three CSOD CSVs on a composite User ID + Training Object ID key, conditionally backfills assignment attribution for event/session types, and resolves due dates from curriculum records. The second reshapes long-format survey exports — mapping 8+ question IDs to clean column names — then pivots to one row per learner per course, preserving all identity fields.

What it Enabled
  • Power BI could now load and transform the full L&D dataset without timeouts — previously impossible at this row count without a database
  • Assignment attribution was correctly populated for event/session completions, fixing a systematic gap in compliance reporting
  • Survey responses became analyzable in Power BI the same day exports ran, collapsing a full day of manual reshaping to a script execution
  • Both scripts are parameterized by month — updating one variable reruns the entire pipeline

Which markets will be understaffed over the next two quarters, and how much revenue is at risk if we don't act?

Sales leadership had no systematic way to see whether hiring was keeping pace with demand growth by market. Headcount gaps were visible only in hindsight, and prioritization was based on raw rep count rather than revenue impact. This model changed that: it forecasts both demand-implied need and headcount trajectory per market, then ranks markets by ramp-adjusted revenue at risk so the right ones get filled first.

Mountain West: widening gap between demand-implied need and headcount
Approach

Built a star schema in BigQuery (SCD Type 2 rep dimension, partitioned/clustered fact tables) and wrote analysis SQL covering credibility-weighted attrition, ramp curve by tenure band, and demand-implied staffing gaps. A Python script then fits OLS regressions per market on both demand need and headcount trajectory, forecasts six months forward, and converts the projected gap to ramp-adjusted revenue at risk. The staffing target itself is derived from healthy markets via a density regression rather than assumed — the same logic a recruiter would use to set sustainable req capacity per person.

Methodology Decisions
  • Credibility-weighted attrition (k=8) shrinks small-team rates toward the org mean, so a single departure on a 5-person team doesn't read as a trend
  • Ramp discount (65%) on revenue-at-risk accounts for the fact that a backfill hired today won't produce at full quota immediately — the dollar figure is honest, not inflated
  • Revenue ranks markets, not headcount — a 1-rep gap in a high-value market outweighs a 2-rep gap in a small one, which is the prioritization a staffing function exists to provide
  • Derived staffing target from density regression on healthy markets, not a hand-assigned tier — removes a common credibility problem with workforce models

WITH hc AS (
  SELECT snapshot_date, market_id, COUNT(*) AS active_reps
  FROM fact_headcount_snapshot GROUP BY 1,2

  mk.market_name,
  ROUND(dm.dealer_count / mk.target_dealers_per_rep, 1) AS demand_implied_need,
  hc.active_reps,
  ROUND(dm.dealer_count / mk.target_dealers_per_rep - hc.active_reps, 1) AS staffing_gap
FROM fact_market_demand dm
JOIN dim_market mk USING (market_id)

ORDER BY staffing_gap DESC;

-- 1) Active headcount by market x month
SELECT h.snapshot_date, m.market_name, m.region, COUNT(*) AS active_reps
FROM fact_headcount_snapshot h
JOIN dim_market m USING (market_id)
GROUP BY 1,2,3;

-- 2) Credibility-weighted attrition (k=8: shrinks small-team rates toward org mean)
WITH joined AS (
  SELECT hc.market_id, hc.ym, hc.headcount,
         COALESCE(m.terms,0) AS terms,
         SAFE_DIVIDE(COALESCE(m.terms,0), hc.headcount) AS raw_rate
  FROM hc LEFT JOIN monthly m
    ON hc.market_id=m.market_id AND hc.ym=m.term_year_month
),
org AS (SELECT AVG(raw_rate) AS org_mean FROM joined)
SELECT
  j.market_id, mk.market_name,
  ROUND(AVG( (j.headcount/(j.headcount+8))*j.raw_rate
           + (8/(j.headcount+8))*o.org_mean ),4) AS cred_weighted_attr
FROM joined j CROSS JOIN org o
JOIN dim_market mk USING (market_id)
GROUP BY 1,2;

-- 3) Ramp curve: quota attainment by tenure band
SELECT
  CASE WHEN h.tenure_months < 3  THEN '0-2 mo'
       WHEN h.tenure_months < 6  THEN '3-5 mo'
       WHEN h.tenure_months < 12 THEN '6-11 mo'
       ELSE '12+ mo' END AS tenure_band,
  ROUND(AVG(p.quota_attainment_pct),3) AS avg_attainment
FROM fact_sales_performance p
JOIN fact_headcount_snapshot h
  ON p.rep_id=h.rep_id AND p.snapshot_date=h.snapshot_date
GROUP BY 1 ORDER BY MIN(h.tenure_months);

-- 4) Demand-implied need vs headcount
SELECT
  mk.market_name, dm.dealer_count, mk.target_dealers_per_rep,
  ROUND(dm.dealer_count / mk.target_dealers_per_rep, 1) AS demand_implied_need,
  hc.active_reps,
  ROUND(dm.dealer_count / mk.target_dealers_per_rep - hc.active_reps, 1) AS staffing_gap
FROM fact_market_demand dm
JOIN dim_market mk USING (market_id)
JOIN hc ON hc.snapshot_date=dm.snapshot_date AND hc.market_id=dm.market_id
ORDER BY snapshot_date DESC, staffing_gap DESC;
Deriving the staffing target from healthy markets via OLS in pure SQL
-- Step 1: find healthy markets (consistent quota attainment, enough months)
WITH healthy AS (
  SELECT market_id FROM fact_sales_performance
  GROUP BY market_id
  HAVING AVG(quota_attainment_pct) >= 0.90
     AND COUNT(DISTINCT snapshot_date) >= 6
),
-- Step 2: measure actual dealers-per-rep in healthy markets (recent 3 months)
obs_dpr AS (
  SELECT d.market_id,
         AVG(SAFE_DIVIDE(d.dealer_count, ra.active_reps)) AS obs_dealers_per_rep
  FROM fact_market_demand d JOIN recent_active ra USING (market_id, snapshot_date)
  WHERE d.market_id IN (SELECT market_id FROM healthy) GROUP BY 1
),
-- Step 3: OLS slope + intercept across healthy markets (dealers_per_rep ~ density)
fit AS (
  SELECT
    COVAR_POP(m.density_score, o.obs_dealers_per_rep)
      / NULLIF(VAR_POP(m.density_score), 0)                         AS slope,
    AVG(o.obs_dealers_per_rep)
      - (COVAR_POP(m.density_score, o.obs_dealers_per_rep)
         / NULLIF(VAR_POP(m.density_score), 0)) * AVG(m.density_score) AS intercept
  FROM obs_dpr o JOIN dim_market m USING (market_id)
)
-- Step 4: apply fitted relationship to every market via its density score
SELECT
  m.market_name, m.density_score,
  ROUND(f.intercept + f.slope * m.density_score, 1) AS derived_target_dealers_per_rep
FROM dim_market m CROSS JOIN fit f
ORDER BY derived_target_dealers_per_rep DESC;

-- Derives target_dealers_per_rep per market from structural driver (density)
-- rather than assuming a hand-assigned tier. Same logic as deriving recruiter
-- req capacity from workload, not job title.
WITH
healthy AS (
  SELECT market_id FROM fact_sales_performance
  GROUP BY market_id
  HAVING AVG(quota_attainment_pct) >= 0.90
     AND COUNT(DISTINCT snapshot_date) >= 6
),
recent_active AS (
  SELECT market_id, snapshot_date, COUNT(*) AS active_reps
  FROM fact_headcount_snapshot GROUP BY 1,2
),
obs_dpr AS (
  SELECT
    d.market_id,
    AVG(SAFE_DIVIDE(d.dealer_count, ra.active_reps)) AS obs_dealers_per_rep
  FROM fact_market_demand d
  JOIN recent_active ra USING (market_id, snapshot_date)
  WHERE d.market_id IN (SELECT market_id FROM healthy)
    AND d.snapshot_date >= DATE_SUB((SELECT MAX(snapshot_date) FROM fact_market_demand), INTERVAL 2 MONTH)
  GROUP BY d.market_id
),
fit AS (
  SELECT
    COVAR_POP(m.density_score, o.obs_dealers_per_rep) / NULLIF(VAR_POP(m.density_score), 0) AS slope,
    AVG(o.obs_dealers_per_rep) - (COVAR_POP(m.density_score, o.obs_dealers_per_rep)
      / NULLIF(VAR_POP(m.density_score), 0)) * AVG(m.density_score) AS intercept
  FROM obs_dpr o JOIN dim_market m USING (market_id)
)
SELECT
  m.market_id, m.market_name, m.density_score,
  o.obs_dealers_per_rep,
  ROUND(f.intercept + f.slope * m.density_score, 1) AS derived_target_dealers_per_rep
FROM dim_market m CROSS JOIN fit f
LEFT JOIN obs_dpr o USING (market_id)
ORDER BY derived_target_dealers_per_rep DESC;

import numpy as np
import pandas as pd
from sklearn.linear_model import LinearRegression

FORECAST_MONTHS = 6    # two quarters
CRED_K          = 8    # credibility weight for attrition shrinkage

# Load warehouse tables (or swap for BigQuery queries)
dim_market = pd.read_csv(f"{DATA_DIR}/dim_market.csv")
hc   = pd.read_csv(f"{DATA_DIR}/fact_headcount_snapshot.csv",  parse_dates=["snapshot_date"])
md   = pd.read_csv(f"{DATA_DIR}/fact_market_demand.csv",       parse_dates=["snapshot_date"])
perf = pd.read_csv(f"{DATA_DIR}/fact_sales_performance.csv",    parse_dates=["snapshot_date"])

# Monthly series: demand-implied need + actual headcount
hc_m = hc.groupby(["market_id","snapshot_date"]).size().reset_index(name="active_reps")
md_m = md.merge(dim_market[["market_id","market_name","target_dealers_per_rep","avg_deal_value_base"]], on="market_id")
md_m["demand_need"] = md_m["dealer_count"] / md_m["target_dealers_per_rep"]
series = md_m.merge(hc_m, on=["market_id","snapshot_date"], how="left")

# Revenue per rep: ramp-blended actuals, recent 3-month avg per market
rev_per_rep  = perf.groupby(["market_id","snapshot_date"])["revenue"].sum().reset_index().merge(hc_m, on=["market_id","snapshot_date"])
rev_per_rep["rev_per_rep"] = rev_per_rep["revenue"] / rev_per_rep["active_reps"]
recent_rpr   = rev_per_rep.sort_values("snapshot_date").groupby("market_id").tail(3).groupby("market_id")["rev_per_rep"].mean()

def forecast_series(dates, values, horizon):
    x     = np.arange(len(values)).reshape(-1,1)
    model = LinearRegression().fit(x, np.asarray(values, dtype=float))
    fx    = np.arange(len(values), len(values)+horizon).reshape(-1,1)
    fdates = pd.date_range(dates.max(), periods=horizon+1, freq="ME")[1:]
    return fdates, np.clip(model.predict(fx), 0, None), model

risk_rows = []
for mid, g in series.groupby("market_id"):
    _, need_fc, _ = forecast_series(g["snapshot_date"], g["demand_need"], FORECAST_MONTHS)
    _, hc_fc,   _ = forecast_series(g["snapshot_date"], g["active_reps"],  FORECAST_MONTHS)
    gap_fc = need_fc - hc_fc

    rpr          = float(recent_rpr.get(mid, np.nan))
    ramp_discount = 0.65
    avg_gap      = float(np.clip(gap_fc, 0, None).mean())
    rev_at_risk  = avg_gap * rpr * ramp_discount * FORECAST_MONTHS

    risk_rows.append({"market_id":mid, "avg_forecast_gap_reps":round(avg_gap,2),
